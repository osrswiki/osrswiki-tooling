# OSRS Wiki tooling

Shared tooling, map asset manifests, and scripts used by the unofficial OSRS Wiki mobile apps.

## What this tree is

This public snapshot holds **shared tooling** that both app trees consume: build/helper scripts, map asset manifests, and related utilities. Day-to-day development happens in a private fleet; what you see here is a **published projection**, not the full private monorepo.

## Apps

- [Android app repository](https://github.com/osrswiki/osrswiki-android)
- [iOS app repository](https://github.com/osrswiki/osrswiki-ios)
